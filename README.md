# Service Booking Platform

Internship group project — service discovery, booking, provider dashboard, and admin panel.

## Docs

- [Team assignments](docs/TEAM_ASSIGNMENTS.md)
- [Project structure](docs/PROJECT_STRUCTURE.md)

## Quick start (after dependencies are installed)

```bash
npm install
npm run dev:server
npm run dev:web
```

- API health: `http://localhost:4000/health`
- Web app: `http://localhost:3000`
